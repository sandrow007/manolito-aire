Política de Privacidad y Seguridad de Datos

No hay cuentas ni perfiles publicitarios. Las preferencias se guardan localmente, pero algunas funciones envían consultas a servicios externos. Según la función, pueden transmitirse coordenadas, búsquedas o mensajes del chat; los proveedores también reciben datos técnicos como la IP. Aquí detallamos esos flujos.

1. Qué datos no solicitamos para crear una cuenta

No solicitamos correo, nombre, contraseña ni teléfono para crear una cuenta, y no creamos perfiles publicitarios. Aun así, tu uso no es anónimo frente a toda infraestructura: el alojamiento y los proveedores externos pueden recibir la IP y metadatos técnicos habituales. Las coordenadas o textos que necesita cada función se describen en esta política.

2. Almacenamiento local en tu navegador

Algunas preferencias (por ejemplo, idioma, tema y opciones de accesibilidad), estados de interfaz y cachés pueden guardarse en localStorage o sessionStorage del navegador. Son almacenamientos locales, no cuentas ni sincronización con un perfil. Su contenido puede persistir según el tipo de almacenamiento hasta que caduque, se sobrescriba o borres los datos del sitio desde el navegador.

3. El Asistente de Manolit∞ (Privacidad en Consultas con IA)

Al usar el chat, el mensaje escrito y una selección breve de mensajes recientes pueden enviarse a un servicio externo de inteligencia artificial para generar la respuesta. El sitio no asocia la consulta a una cuenta, pero el proveedor recibe el contenido enviado y puede tratarlo conforme a sus propias condiciones.

El endpoint del sitio utiliza Cloudflare Workers AI. Si ese servicio falla y hay una clave de respaldo configurada, la consulta y el contexto breve pueden reenviarse a OpenRouter. El reenvío implica que el proveedor alternativo también recibe el contenido de la conversación necesario para contestar.

No incluyas contraseñas, datos médicos identificables, direcciones exactas ni información personal de otras personas. El historial que ves puede mantenerse temporalmente en el navegador para dar contexto a la conversación; no se crea una cuenta ni una base de datos propia de chats. La conservación y el tratamiento por parte de los proveedores dependen de sus políticas y condiciones vigentes.

4. Datos de Ubicación GPS, Hora Local y Posición Solar

La ubicación del dispositivo es opcional y solo se obtiene si autorizas el permiso del navegador; también puedes elegir o escribir una zona manualmente. La posición solar se calcula con la ubicación y hora seleccionadas para mostrar el resultado.

Si una función necesita datos meteorológicos o de calidad del aire, transmite las coordenadas consultadas a los servicios correspondientes, por ejemplo a través de los proxies del sitio que consultan Open-Meteo/CAMS. El navegador puede solicitar permiso para usar la ubicación del dispositivo; también puedes indicar una zona manualmente. Los cálculos de posición solar, sombras y ruta peatonal basada en sombras se ejecutan localmente. Otras funciones de mapas, búsqueda o rutas pueden transmitir consultas o coordenadas a proveedores externos, según se explica aquí. Manolit∞ no crea perfiles ni mantiene deliberadamente una base de datos de historial personal de GPS o búsquedas. Los proveedores y la infraestructura de alojamiento pueden procesar IP y registros técnicos conforme a sus propias condiciones.

5. Búsqueda de Direcciones y Rutas con Sombra 3D

Al buscar una dirección, el texto se envía al geocodificador utilizado (actualmente Photon/Komoot a través del proxy; otras funciones pueden usar otros servicios). Las coordenadas resultantes o el área consultada pueden enviarse al proveedor de rutas, como OSRM/FOSSGIS o BRouter. Las teselas, geometrías y edificios se solicitan a los proveedores cartográficos activados, como OpenFreeMap, IGN o Catastro.

Las solicitudes pueden incluir IP, metadatos técnicos, el texto buscado, coordenadas de origen/destino o la caja geográfica necesaria. Si pasan por el proxy, este procesa la petición y puede aplicar caché técnica; ante fallos, el navegador puede consultar directamente al proveedor. No adjuntamos deliberadamente nombre o cuenta, pero los terceros pueden registrar solicitudes conforme a sus políticas. Manolit∞ no mantiene un historial propio de búsquedas o rutas. Evita introducir datos que te identifiquen directamente.

6. Datos de Nubosidad en Tiempo Real (OpenWeatherMap)

Para mostrar la cobertura nubosa y las teselas de OpenWeatherMap, la web usa un proxy de Cloudflare Workers. El navegador envía las coordenadas de la zona consultada (centro del mapa o punto de referencia seleccionado) y, para las teselas, las coordenadas de cada tesela visible. La clave de API se mantiene en el proxy. Algunas respuestas pueden almacenarse temporalmente en caché técnica; Cloudflare y OpenWeatherMap pueden procesar IP y metadatos de solicitud según sus propias políticas. La petición de clima no adjunta tu nombre o una cuenta. Puedes evitar usar «Mi ubicación» y consultar una zona elegida manualmente.

7. Capa del Catastro de España (Parcelas y Alturas)

Al activar «Catastro 3D», el mapa solicita imágenes del WMS de la Sede Electrónica del Catastro, mediante el proxy de Cloudflare Workers configurado para esta capa. La petición necesita las coordenadas de las teselas visibles; puede incluir IP y metadatos técnicos en la infraestructura de red. El proxy aplica caché técnica temporal (aproximadamente una hora según la configuración), sin mantener deliberadamente un historial personal de consultas. El proveedor y la infraestructura aplican sus propias condiciones.

8. Tipografías web (Google Fonts)

Algunas páginas, incluida «Comparativa», cargan tipografías desde Google Fonts. Si esas fuentes externas se solicitan, Google recibe la petición técnica (que puede incluir IP, agente de usuario y cabeceras de conexión) y la trata conforme a su propia política. En otras secciones puede utilizarse una pila de fuentes del sistema. No adjuntamos deliberadamente nombre o cuenta a estas peticiones.

9. Juego y Certificado de Protección Climática

El juego «Atrapa a Manolit∞» y su certificado se generan en el navegador: el nombre, la puntuación y el número simbólico no se envían deliberadamente a Manolit∞ ni se registran en una cuenta. La página, como cualquier recurso web, sí genera solicitudes técnicas al servidor que la entrega. El contenido descargado se queda en tu dispositivo salvo que decidas compartirlo tú.

10. Aparcamientos y planificador de viaje

La capa de aparcamientos consulta objetos de OpenStreetMap en el área visible, normalmente mediante el proxy de Manolit∞; ese servicio recibe el área consultada y puede almacenar temporalmente respuestas en caché. El planificador envía el texto escrito al geocodificador y las coordenadas resultantes a OSRM/FOSSGIS para trazar el viaje. Si eliges usar la ubicación actual como origen, las coordenadas necesarias pueden salir del navegador hacia el servicio de rutas, directamente o a través del proxy. No adjuntamos deliberadamente tu nombre ni una cuenta y no mantenemos un historial propio de trayectos. Los proveedores reciben IP y metadatos de conexión según sus propias políticas.

11. Consultas a servicios externos y registros técnicos

Para servir la página, la infraestructura de alojamiento (incluido Cloudflare cuando interviene) procesa las solicitudes web y puede generar registros técnicos de seguridad y funcionamiento, como IP, fecha/hora, ruta solicitada y agente de usuario, conforme a sus condiciones y plazos. Los proxies de Manolit∞ pueden usar caché temporal para respuestas cartográficas o meteorológicas; no se usa esa caché para crear un perfil personal. Cuando el navegador recurre directamente a un tercero, ese proveedor recibe también la IP y los datos necesarios para la consulta. No controlamos sus registros ni sus periodos de conservación: consulta las políticas de cada proveedor enlazado.

12. Asistente de IA: proveedores y contexto enviado

El chat envía el mensaje escrito y, cuando se usa, una selección breve de mensajes recientes de la conversación al endpoint de Manolit∞, que lo procesa con Cloudflare Workers AI. Si ese proveedor falla y existe configuración de respaldo, el texto y el contexto se pueden reenviar a OpenRouter para generar la respuesta. La conversación se conserva temporalmente en la interfaz del navegador para mantener el contexto, pero Manolit∞ no mantiene una cuenta ni una base de datos propia de conversaciones. Los proveedores pueden procesar o conservar datos conforme a sus propias políticas y condiciones; evita incluir información identificable, sensible, médica o de terceros.

13. Cómo proteger mejor tu privacidad

Puedes no conceder el permiso de ubicación y elegir una zona manualmente; ten presente que las búsquedas o rutas que solicites aún pueden enviar coordenadas a sus proveedores. Evita incluir datos personales, direcciones exactas o información de salud en el chat. Para borrar preferencias y cachés locales, elimina los datos del sitio desde tu navegador. Para solicitudes relacionadas con datos personales o privacidad, escribe a SANDRO.A007@GMAIL.COM; las peticiones a proveedores externos también pueden requerir contacto con ellos.

14. Derechos de los Usuarios y RGPD

Puedes ejercer los derechos que correspondan respecto de los datos personales tratados por el titular, así como solicitar información, escribiendo a SANDRO.A007@GMAIL.COM. Manolit∞ no mantiene cuentas ni perfiles de usuario y no conserva deliberadamente un historial propio de rutas o búsquedas; por ello puede no disponer de datos que permitan identificar una consulta concreta. Los tratamientos independientes de proveedores externos deben gestionarse también ante dichos proveedores. Si consideras que el tratamiento infringe la normativa, puedes reclamar ante la Agencia Española de Protección de Datos.

15. Capa de fuentes de agua y privacidad de ubicación

Al activar «Fuentes de agua», la aplicación consulta la caja geográfica visible del mapa; no solicita GPS específicamente para esta capa. La caja se envía directamente a Overpass y, según la cobertura, a datos municipales de Valencia o Málaga (en este último caso, el conjunto puede descargarse y filtrarse localmente). Manolit∞ no guarda un historial propio de consultas; los servicios externos reciben IP y metadatos técnicos y podrían registrar las solicitudes conforme a sus políticas.

16. Carril bici, rutas en bicicleta y transporte público

Las rutas en bicicleta pueden enviar coordenadas del trayecto al proxy de Manolit∞ para consultar OSRM/FOSSGIS; si no hay resultado, se puede intentar BRouter. La capa de carriles bici consulta Overpass mediante el proxy y puede recurrir a una conexión directa si el proxy no responde. En ambos casos se transmiten las coordenadas necesarias y los proveedores o la infraestructura pueden recibir IP y metadatos técnicos; no se adjunta deliberadamente un nombre o una cuenta.

La capa de transporte público consulta Transitous y OpenStreetMap/Overpass para mostrar paradas; al pedir salidas se transmite el identificador de la parada. Si el proxy no responde, el navegador puede consultar directamente a esos proveedores, que reciben IP y metadatos técnicos. Puede haber caché temporal de respuestas para evitar peticiones repetidas; Manolit∞ no conserva un historial propio de consultas. Las políticas y retención de proveedores externos dependen de cada servicio.
